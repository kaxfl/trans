# 60 秒演示脚本

> 目标：让评委在 **60 秒内**看懂"这个软件解决什么问题、和别人有什么不同"。
> 素材页：`demo/demo.html`（用浏览器打开即可）

---

## 两种演示方式，选一个

### 方式 A：代码生成的动画（推荐，最稳）

打开 `demo/animation.html`，**全屏（F11）**，然后：

```
Alt + F9  开始录制 → 等一轮动画跑完（约 20 秒，自动循环）
Alt + F9  停止
```

**优点**：
- **不依赖 Ollama、不依赖网络、不会卡顿**——评委机器上也能直接放
- 时间轴固定，不会"手抖漏了某一步"
- 动画里的弹窗样式直接沿用程序真实的 CSS，不是随便画的

**用法**：双击文件用浏览器打开即可，无需安装任何东西。

> 想定格到某一帧看效果：地址栏加 `?t=3.5`（划词）、`?t=6.5`（整句）、`?t=10`（本地词典）、`?t=15`（标识符拆词）。

### 方式 B：真实录屏（可信度最高）

按下面"录制前准备"操作，用 NVIDIA App 录真实操作。
**优势是"真的在跑"**；风险是环境问题（模型没预热、弹窗没出）会毁掉素材。

**如果时间允许：两个都做**——动画放 PPT 里循环播，录屏作为附录证明真实可用。

## 录制前准备（花 5 分钟，能省掉无数次重录）

**1. 预热本地模型** ← 最重要，别跳过

第一次调用模型要 7 秒（从磁盘加载进显存），**录进去会很难看**。先手动跑一次把模型烫热：

```powershell
# 启动 Ollama
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" serve

# 预热（等它返回，之后再录，翻译就是 0.5–1 秒）
$body = @{ model="qwen3:1.7b"; stream=$false; messages=@(@{role="user";content="翻译成简体中文：hello world"}) } | ConvertTo-Json -Depth 5
$ProgressPreference = 'SilentlyContinue'
Invoke-RestMethod -Uri "http://127.0.0.1:11434/v1/chat/completions" -Method Post `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) -ContentType "application/json" -TimeoutSec 120
```

**2. 确认程序在跑**

```powershell
Stop-Process -Name tauri-app -Force -ErrorAction SilentlyContinue
cd "E:\deepseekharness\Translate_project\translator\src-tauri\target\release"
.\tauri-app.exe
```

**3. 打开素材页**

```powershell
start "E:\deepseekharness\Translate_project\translator\demo\demo.html"
```

浏览器里 **Ctrl + 加号** 放大到 **125%**，让文字在视频里够大。

**4. 关掉干扰**
- 开「专注助手」（Win+A → 专注助手 → 仅闹钟），避免弹通知
- 关掉微信/QQ 弹窗
- 别设 `JFY_SELECTION_DEBUG`（会写日志，影响性能）

**5. 录制（NVIDIA App）**

你装的是**新版 NVIDIA App**，快捷键：

| 操作 | 快捷键 |
|---|---|
| 打开录制面板 | `Alt + Z` |
| **开始 / 结束录制** | **`Alt + F9`** |
| 保存最近 5 分钟（回溯录制） | `Alt + F10` |

**⚠️ 先做这一步，否则录出来是黑的：**

NVIDIA App 默认**只录游戏窗口**，不录桌面和普通程序。要录浏览器必须打开桌面捕获：

```
Alt + Z → ⚙ 设置 → 隐私控制 → 打开「桌面捕获 / Desktop Capture」
```

**建议录制设置**：

```
Alt + Z → ⚙ 设置 → 视频捕获
  分辨率: 1080p (或与显示器一致)
  帧率:   60 FPS
  码率:   20 Mbps 以上
```

录完的视频默认在 `Videos\NVIDIA` 目录下。

## 分镜（60 秒）

### 0:00 – 0:10　先讲问题

**画面**：浏览器素材页，鼠标停在 Overview 段落上。

**旁白（可照读）**：
> "读英文代码和技术文档时，最烦的不是看不懂，而是**切屏、忘了、切回来、再查一遍**。这个工具把这几步压成了一步。"

---

### 0:10 – 0:24　查单词：离线词典，秒出

**动作**：
1. 滚到 **Common Terms**
2. **双击** `compile` → 弹窗出现
3. 停顿 2 秒让人看清：音标 / ★★ / `vt. 编译, 编辑, 编纂`
4. 鼠标移到弹窗上（**弹窗不会消失**，正好讲解）
5. 鼠标移出选区 → 弹窗消失
6. **双击** `inventory` → 再弹一次，证明是通用的

**旁白**：
> "双击任意一个单词——**不看网络、不调模型**，本地词典直接查表。音标、常用度星级、按词性分类的多个释义，**毫秒级**。"

**如果卡顿**：说明模型没预热或者词典没加载。先回去检查。

---

### 0:24 – 0:42　代码标识符拆词（这是核心差异化，多给时间）

**动作**：
1. 滚到 **Configuration** 的代码块
2. **双击** `lastUpdateTime`
3. **停 3 秒**，让人看清拆成这样：
   ```
   lastUpdateTime
   last      → 最后 / 上一次
   Update    → 更新
   Time      → 时间
   ```
4. 再双击 `userProfileCacheInvalidator` —— 显示能处理更长的标识符
5. 双击 `BUYOUT_SECRET` —— 显示全大写常量被识别为缩写，保留原样

**旁白**：
> "这是它和普通翻译软件最大的不同。选中标识符，它不会把整个词硬翻成一个怪词，而是按 `snake_case` 和 `camelCase` **拆成词根，逐词给出含义**。全大写的常量会被识别出来，保留原样。"
>
> "对英语不好的初学者，这比一句通顺的译文有用得多——你是在猜这个名字在说什么，不是在读文章。"

---

### 0:42 – 0:56　句子翻译：本地模型

**动作**：
1. 回到 **Overview**
2. **拖拽选中**第一段整段
3. 弹窗先显示「翻译中…」，然后 **约 0.5 秒**出译文
4. **停 3 秒**看译文
5. 再拖选第二段，证明稳定

**旁白**：
> "整段也能翻。默认走本地模型——**内容不出这台机器**，完全离线。首次调用要加载模型会慢一点，之后就快了。"

**如果本地模型没起来**：会显示「⚠ 已回退到 MyMemory」，这时候说：
> "本地模型没启动时会自动回退到云端免费接口，不会失灵。"

> **实测参考**（RTX 4050，qwen3:1.7b，预热后）：
> 整段 144 字符 **554 ms** / 代码标识符 **173 ms** / 单词走词典 **微秒级**。
> 冷启动首调约 2–3 秒，所以**录制前一定要预热**。

---

### 0:56 – 1:10　收尾

**动作**：鼠标移开，弹窗消失。停在干净的页面上。

**旁白**：
> "整个工具是**一次点击级别**的交互：选中、出现、移开、消失。"
>
> "技术上有三层：本地词典负责单词，本地小模型负责句子，识别符拆词负责代码。**核心功能完全离线、零调用成本**，模型是可选的增强项。"

## 备用方案（万一现场出问题）

| 情况 | 应对 |
|---|---|
| 本地模型起不来 | 只演**单词**和**标识符**——这两个走本地词典，绝对离线可用 |
| 网络也没有 | **也是只演这两个**。这恰好可以强调"核心功能零依赖" |
| 弹窗第一次没出来 | 用 `Alt + .` 快捷键（选中后按），比悬停更稳 |
| 某个软件里取词失败 | 强调这是已知限制，并演示 `Alt + .` 和「框选」两个兜底 |

## 三个可以加分的说法

评委通常记不住功能，但记得住**判断**。以下三句都是实话，可以自然带出：

1. **"查单词和翻句子是两种需求，不该用同一个方案。"**
   词典查表 26 微秒，模型推理 1 秒——用模型查单词是浪费。

2. **"我不用 UIA 取词，因为它不可靠。"**
   Chrome、VSCode、IDEA 默认都不暴露选区，游戏和自绘界面永远不暴露。所以主路径是全局钩子 + 剪贴板，UIA 只做辅助。

3. **"这个工具最开始是给我自己用的。"**
   做游戏模组时看不懂英文代码，做完之后自己每天在用。**真实需求驱动的软件，细节会自然地对**。
