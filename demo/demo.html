Overview

拖拽选中下面任意一句 → 松手即出译文

The translation service keeps a small in-memory cache so that repeated lookups of the same phrase return instantly without touching the network. When the cache misses, the request is forwarded to a local model first, and only if that model is unavailable does it fall back to a remote endpoint.

Every selection is captured with a global mouse hook rather than accessibility APIs, because most applications do not expose their text selection to the system. The hook only decides whether a selection happened; the actual text extraction is performed on a worker thread, so the operating system's input queue is never blocked.
