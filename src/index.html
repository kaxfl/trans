设置

浅色主题更适合白天和明亮环境；「跟随系统」会随 Windows 的深浅色设置自动切换。

「自动」：选中中文 → 译成英文，其它语言 → 译成中文。
选定具体语言则固定译成该语言；同名语言之间会自动换向，避免「中译中」变成空白。

免费引擎可随时切换；付费引擎（如 DeepL、智谱）后续版本开放。

左边填服务地址，右边填模型名。默认对接 Ollama：先装 Ollama，再 ollama pull qwen3:1.7b，然后点「测试连接」。也可填 llama.cpp / LM Studio 的地址。

不想装 Ollama、又要比免费引擎好的翻译质量时选它。按量计费：一次短句翻译不到一分钱，注册还松免费额度。 填好 key 后，到上面「翻译引擎」里切换成 DeepSeek 云端 即可。

双击选中一个词、或拖拽选中一段，译文立刻弹出；鼠标移开选区弹窗自动消失，移回去又能再翻一次。
靠全局鼠标钩子实现，不依赖目标软件的无障碍接口，浏览器 / VSCode / QQ / PDF 阅读器都能用。
如果抓不到，可以：① 选中后按 Ctrl + Alt + .；② 用「框选」按钮（或 Ctrl + Alt + S）走 OCR，译文会直接弹在框选处。

如果觉得"选中就弹"太打扰，点上面的按钮切换成「鼠标移回选区才翻译」。

关掉「划词翻译」后，选中任何文字都不会弹窗（主窗口里手动点「翻译」仍然可用）。
「中文也翻译」默认关闭：只翻译英文，选中中文时不会弹窗——避免点中中文段落就被翻译。
需要临时单次翻译时，按快捷键 Ctrl + Alt + .（可改）。

默认关闭——复制东西时突然跳出一个翻译窗会很打扰（尤其是复制密码、命令、代码时）。
打开后，任何地方 Ctrl+C 都会自动翻译剪贴板内容。需要临时静音时用下面的「暂停监听」。
